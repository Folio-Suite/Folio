# Make the semantic Work canonical

Folio will store an output-independent semantic Work rather than treating pages, markup files, or any publication format as canonical. Print, web, EPUB, and other outputs are derived Renditions of configured Editions, allowing each medium to receive first-class composition without reducing the Work to a lowest-common-denominator format.

## Consequences

Semantics, relationships, accessibility information, and publication metadata must originate in the Work. Layout and rendering systems may add medium-specific behavior, but they must not become the sole owners of intellectual structure or meaning.
